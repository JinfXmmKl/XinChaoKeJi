# 北京心潮科技有限公司 · 官方网站

高端科技感 / 未来科幻风格的企业官网，纯静态实现，无任何构建依赖。

## 目录结构

```
GW/
├── index.html      # 页面结构（首屏 / 关于我们 / 核心业务 / 技术实力 / 联系我们）
├── css/style.css   # 全部视觉样式与动画
└── js/main.js      # 粒子网络背景、滚动动效、数字滚动、3D 卡片、终端打字机
```

## 本地预览

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

也可以直接双击 `index.html` 在浏览器中打开（字体加载需联网）。

## 部署

纯静态站点，可直接部署到任意静态托管服务（Nginx、GitHub Pages、Vercel、阿里云 OSS 等），将三个文件/目录原样上传即可。

## 主要特效

- 全屏粒子网络背景，随鼠标产生引力交互
- 首屏 3D 透视网格地面 + 渐变光球 + 数字滚动统计
- 滚动浮现动画（IntersectionObserver，性能友好）
- 业务卡片 3D 倾斜 + 鼠标光晕跟随
- 全息扫描风格的企业视觉框、技术能力进度条
- 模拟终端打字机效果、无缝滚动技术关键词跑马灯
- 响应式设计，适配手机 / 平板 / 桌面；支持 `prefers-reduced-motion`
